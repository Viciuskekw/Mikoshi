# Decisões do projeto

Estas decisões definem os limites para o desenvolvimento do Mikoshi:

1. O aprendizado contínuo acontece por conversa natural.
2. A importação aceita conversas exportadas do WhatsApp, Telegram, Discord e formatos genéricos, sempre com revisão, anonimização e controle do usuário.
3. Dados de terceiros não são transformados automaticamente em memória pessoal.
4. Perfis e memórias são criados por análise, sem retreinar os pesos do modelo.

Este registro documenta decisões de produto; não implementa essas funcionalidades.
