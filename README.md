# Mikoshi

Ambiente inicial do projeto Mikoshi.

## Ambiente

- Windows 10 64 bits
- Python 3.14.10 (instalado no perfil do usuário)

Neste terminal do Codex, use o caminho direto do interpretador para conferir a versão:

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python314\python.exe" --version
```

## Diretrizes do projeto

- O aprendizado contínuo acontece por conversa natural.
- Conversas exportadas do WhatsApp, Telegram, Discord e formatos genéricos podem ser importadas com revisão, anonimização e controle do usuário.
- Dados de terceiros não se tornam automaticamente memória pessoal.
- Perfis e memórias são criados por análise; os pesos do modelo não são retreinados.

Este repositório contém apenas a estrutura inicial. Nenhuma funcionalidade do aplicativo foi implementada.
